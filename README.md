# ClashBlocks Website

Static website prepared for GitHub Pages.

- Entry file: `index.html`
- Custom domain: `clashblocks.net` (configured in GitHub Pages settings)
- Minecraft server IP shown on the site: `clashblocks.qzz.io`
- Discord invite: https://discord.gg/8X6k9hyhc

After uploading these files to the repository root, enable GitHub Pages in Settings → Pages and choose Deploy from a branch, branch `main`, folder `/(root)`. Add `clashblocks.net` in the Custom domain field. Configure DNS at the domain registrar only after adding the domain in GitHub Pages settings.
